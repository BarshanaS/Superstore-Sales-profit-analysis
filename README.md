# Superstore Sales & Profit Analysis

## Project Overview
An Excel-based sales and profit analysis project created using the Superstore dataset.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts
- Slicers
- Conditional Formatting
- Dashboard

## Workbook Structure
- **Raw Data** – Original Superstore dataset
- **Pivot Table** – Data analysis and summarized calculations
- **Dashboard** – Interactive sales and profit dashboard

## Key Analysis
- Total Sales
- Total Profit
- Total Orders
- Returned Orders
- Profit Margin
- Sales by Year
- Sales by Region
- Sales by Segment
- Sales by Sub-Category
- Product-level analysis
- Profit Achievement

## Dashboard Features
- Interactive slicers
- KPI cards
- Pivot-based charts
- Sales and profit analysis
- Achievement tracking

## Purpose
This project was created to practise Excel-based data cleaning, analysis, reporting, visualization, and dashboard creation using a real-world-style sales dataset.
